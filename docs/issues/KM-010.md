## Summary
Prepare the *public information* URLs needed by the Tracing Guatemala team's planned Google login. Google OAuth client and token logic stay in the **private application** repository.

## Acceptance criteria
- [ ] Verify current Google Auth Platform branding, authorized domains, app verification and privacy URL requirements for actual requested scopes.
- [ ] Confirm product name, clear project landing URL (`https://krunchymonkey.dev/tracing-guatemala/`) and finalized public privacy URL match Google Cloud configuration.
- [ ] Document that Google login may return to an HTTPS **private LAN callback** only if client browser DNS, TLS, and redirect-URI rules work as tested.
- [ ] Confirm approved-account authorization, session management and CSRF protections are implemented in Tracing Guatemala backend—not this static repository.
- [ ] No OAuth client secret, access token or callback proxy is committed to public-site code.
- [ ] Record end-to-end sign-in tests and any Google branding/consent review outcome without claiming approval prematurely.

## Dependencies
KM-005 privacy finalization, KM-008 public custom domain, Tracing Guatemala auth issue #168 or successor.

## Technical notes
Static site only hosts information; does not create authenticated access to private data.

## Summary
Add lightweight launch-quality checks without changing the approved aesthetic.

## Acceptance criteria
- [ ] All pages have accurate titles, descriptions, semantic landmarks, alt text and logical headings.
- [ ] Keyboard navigation, focus visibility, touch sizing, reduced-motion and contrast reviewed on desktop/mobile.
- [ ] All public URLs return HTTP 200, expected canonical paths, valid favicon and no broken images.
- [ ] Confirm HTTPS/no mixed content; appropriate metadata and robots choices reviewed.
- [ ] Lighthouse or equivalent sample results recorded for at least homepage and TG page, with improvements justified by impact, not arbitrary scores.
- [ ] No third-party analytics or trackers added without owner approval and corresponding privacy notice update.

## Dependencies
KM-003 mobile design and KM-007 Pages preview.

## Technical notes
Respect visual parity. Avoid heavy framework migrations and stock photography.
## Definition of done
- [ ] Small reviewed PR (or documented owner-only deployment action).
- [ ] Run `python scripts/check_site.py` and `python scripts/build_site.py`; record outcomes.
- [ ] No real family-history/client information, token, credential, local secret location, or private network information is introduced.
- [ ] Update `docs/CLAUDE_HANDOFF.md` and relevant documentation if the implementation decision changes.
- [ ] Don't close until acceptance criteria have actually been verified.

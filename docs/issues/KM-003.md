## Summary
Match the approved 390px mobile mockup and preserve usability on small screens, tablets, keyboard and reduced-motion settings.

## Context
Reference: `docs/reference/home-mobile-390.png`; existing `<details>` navigation and CSS media queries should be reused.

## Acceptance criteria
- [ ] 390px full-page screenshot closely matches baseline layout and section hierarchy.
- [ ] 320px, 390px, 768px and 1024px widths produce no horizontal scrolling or clipped navigation.
- [ ] Mobile menu is operable by touch/keyboard and has sensible focus indication; links close/route correctly.
- [ ] Images have descriptive alt text where meaningful, text contrast remains readable, headings stay hierarchical.
- [ ] `prefers-reduced-motion` is honored; controls have useful accessible names and tap areas.
- [ ] Run desktop and mobile manual or automated browser walkthrough; attach evidence.

## Technical notes
No SPA framework or added dependencies for a CSS/nav fix without clear justification.

- [ ] No real family-history/client information, token, credential, local secret location, or private network information is introduced.
- [ ] Update `docs/CLAUDE_HANDOFF.md` and relevant documentation if the implementation decision changes.
- [ ] Don't close until acceptance criteria have actually been verified.

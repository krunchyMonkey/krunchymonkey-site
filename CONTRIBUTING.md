# Contribution and review expectations

- Open a small issue-linked PR, attach a 1440px desktop screenshot and a 390px mobile screenshot if touching design.
- Run `python scripts/check_site.py` and `python scripts/build_site.py` locally.
- Keep the approved original logo and mockup visual hierarchy intact. Changes to branding require owner approval.
- Privacy policy and OAuth description require review for accuracy against the deployed private application.
- Do not publish real genealogy/client names, addresses, documents, secrets, LAN IPs or screenshots of private customer data.
- Don't change Cloudflare DNS, expose private `tg` host, or use GitHub Pages for the Tracing Guatemala application itself.
